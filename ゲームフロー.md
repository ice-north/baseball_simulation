## 2. イニング進行フロー

### 2.1 攻守の決定

```yaml
表（トップ）:
  攻撃: アウェイチーム
  守備: ホームチーム
  投手: ホームチームの投手
  捕手: ホームチームの捕手

裏（ボトム）:
  攻撃: ホームチーム
  守備: アウェイチーム
  投手: アウェイチームの投手
  捕手: アウェイチームの捕手
```

### 2.2 イニング終了条件

```
3アウト発生時:
  1. アウトカウントを0にリセット
  2. 塁上の走者をクリア
  3. 投手スタミナ +3 回復
  4. イニング得点を記録
  5. 終了判定を実行
```

### 2.3 表裏切替ルール

```javascript
if (newOuts === 3) {
  if (isTopInning) {
    // 表 → 裏へ
    isTopInning = false
  } else {
    // 裏 → 次イニング表へ
    isTopInning = true
    inning++
  }
}
```

## 3. 試合終了条件

### 3.1 通常終了

```yaml
9回表終了時:
  条件: ホーム > アウェイ
  結果: ホームの勝利（9回裏は行わない）

9回裏終了時:
  条件: ホーム ≠ アウェイ
  結果: 得点が多い方の勝利

9回裏途中:
  条件: ホーム > アウェイ になった瞬間
  結果: サヨナラ勝ち（即座に試合終了）
```

### 3.2 延長戦

```yaml
延長突入条件:
  - 9回終了時点で同点

延長ルール:
  - 通常イニングと同じ進行
  - 最大12回まで（maxExtraInnings）

延長終了条件:
  - 延長イニング裏終了時に得点差あり → 勝敗決定
  - 延長イニング裏途中でホームリード → サヨナラ
  - 12回裏終了で同点 → 引き分け
```

### 4.2 結果タイプ別処理

```yaml
ball:
  処理: balls++
  打席終了条件: balls === 4（四球）
  四球時:
    - 打者は1塁へ
    - 満塁なら押し出し（得点+1）
    - それ以外は走者押し出し進塁

called_strike / swinging_strike:
  処理: strikes++
  打席終了条件: strikes === 3（三振）
  三振時:
    - outs++
    - 打者アウト

foul:
  処理: strikes++ （2ストライク未満のみ）
  打席終了: なし

foul_2strike:
  処理: なし（カウント変わらず）
  打席終了: なし

single / double / triple / homerun:
  処理: 走者進塁 + 得点加算
  打席終了: あり
  詳細:
    - advanceRunners() で走者を進める
    - 得点があればスコア加算
    - 各種成績を更新

out:
  処理: outs++
  打席終了: あり
  追加処理:
    - 外野フライ時はタッチアップ判定
    - タッチアップ成功で走者進塁/得点

double_play:
  処理: outs += 2
  打席終了: あり
  追加処理:
    - 1塁走者消滅
```

## 6. 特殊イベント

### 6.1 ワイルドピッチ

```yaml
発生条件:
  - 打席継続中（atBatOver === false）
  - 3アウト未満
  - 走者あり（1塁/2塁/3塁のいずれか）

発生確率:
  基本率: (1 - 制球力/100) × 0.025
  球速補正: (球速-140)/100 を乗算（140km/h以上で影響）
  捕手軽減: 捕手守備力/100 × 0.5 を減算

発生時の処理:
  各走者に対して:
    - 捕手の刺殺判定
    - 成功: 走者アウト
    - 失敗: 1塁進塁（3塁→ホームは得点）
```

### 6.2 盗塁

```yaml
試行条件:
  - 打席継続中
  - 3アウト未満
  - ファウル以外の結果
  - 1塁または2塁に走者あり

試行確率:
  基本: 盗塁スキル^1.5 × 0.35  # 0-35%
  走力ボーナス: 走力/100 × 0.05  # 0-5%
  カウントボーナス: 2ボール以上で +3%
  2アウトボーナス: +2%
  捕手抑止: 捕手肩力/100 × 0.10  # 0-10%
  左投手ペナルティ: +3%（二塁盗塁時）

成功確率:
  基本成功率: 20% + 走力/100 × 60%  # 20-80%
  盗塁スキルボーナス: 0-15%
  球速ペナルティ: (球速-135)/350
  制球ペナルティ: 制球力/100 × 0.05
  捕手阻止: 段階的（低成功率:80%阻止、高成功率:35%阻止）

三塁盗塁:
  - 試行確率: 二塁盗塁の70%
  - 基本成功率: 30% + 走力/100 × 60%  # 30-90%
  - 左投げ捕手ペナルティ: -20%（三塁送球時）
```

### 6.3 タッチアップ

```yaml
発生条件:
  - 外野フライでアウト（isOutfieldFly === true）
  - 3アウト未満
  - 走者あり

判定:
  各走者に対して:
    - 外野手の刺殺確率（tagupThrowbackChance）
    - 走者の走力で成功率補正

  三塁→ホーム:
    成功率 = 1 - (刺殺確率 - 走力/100 × 0.3)
    成功時: 得点+1、犠牲フライ

  二塁→三塁:
    成功率 = 1 - (刺殺確率×0.7 - 走力/100 × 0.2)
    成功時: 走者進塁

  一塁→二塁:
    成功率 = 1 - (刺殺確率×0.5 - 走力/100 × 0.15)
    成功時: 走者進塁
```

### 6.4 四球時の押し出し

```yaml
発生条件:
  - 四球成立（4ボール）
  - 満塁状態（bases = [true, true, true]）

処理:
  - 3塁走者がホームイン（得点+1）
  - 2塁走者 → 3塁
  - 1塁走者 → 2塁
  - 打者 → 1塁
```

## 7. 打順管理

### 7.1 打順進行

```javascript
advanceBatter() {
  if (isTopInning) {
    // アウェイチームの打順を進める
    awayBatterIndex = (awayBatterIndex + 1) % 9
  } else {
    // ホームチームの打順を進める
    homeBatterIndex = (homeBatterIndex + 1) % 9
  }
}
```

### 7.2 打順の維持

```yaml
特徴:
  - 各チームの打順は独立して管理
  - イニングをまたいでも打順は継続
  - 9番の次は1番に戻る

リセット条件:
  - ゲームリセット時のみ1番に戻る
```

## 8. スコア管理

### 8.1 イニング別スコア

```javascript
inningScores = {
  away: [null, null, null, null, null, null, null, null, null],  // 1-9回
  home: [null, null, null, null, null, null, null, null, null]
}

extraInningScores = {
  away: [],  // 10回以降（動的追加）
  home: []
}
```

### 8.2 スコア記録タイミング

```yaml
記録タイミング: イニング終了時（3アウト時）

計算方法:
  1. 累計得点から前イニングまでの合計を引く
  2. 差分がそのイニングの得点

例（5回表終了時）:
  累計得点: 7
  1-4回合計: 5
  5回の得点: 7 - 5 = 2
```

## 9. 成績記録

### 9.1 記録タイミング

```yaml
投球ごと:
  - 投球数 (pitches)
  - 球速履歴

打席終了時:
  打者:
    - 打席数 (plateAppearances)
    - 打数 (atBats) ※四球・犠打除く
    - 安打数 (hits)
    - 本塁打数 (homeruns)
    - 打点 (rbis)
    - 四球 (walks)
    - 三振 (strikeouts)
    - 塁打 (totalBases)
    - 盗塁 (stolenBases)
    - 盗塁死 (caughtStealing)

  投手:
    - アウト数 (outs)
    - 失点 (runsAllowed)
    - 奪三振 (strikeouts)
    - 与四球 (walks)
    - 暴投 (wildPitches)

  捕手:
    - 盗塁阻止 (caughtStealing)
    - 盗塁許可 (stolenBasesAllowed)
    - 暴投阻止 (wildPitchesBlocked)
```

### 9.2 チーム成績

```yaml
チーム単位:
  - 安打数 (teamHits)
  - 打点 (teamRBIs)
  - 失策 (teamErrors)
```

## 10. 状態リセット

### 10.1 イニング終了時リセット

```yaml
リセット対象:
  - アウトカウント → 0
  - 塁上走者 → 全クリア

維持対象:
  - スコア
  - 打順
  - 成績
  - スタミナ（+3回復）
```

### 10.2 ゲームリセット

```yaml
リセット対象:
  - カウント
  - 塁上走者
  - アウトカウント
  - イニング → 1
  - 表裏 → 表
  - スコア → 0-0
  - イニング別スコア
  - 打順 → 1番
  - スタミナ → 最大値
  - 全成績
  - 投球ログ
  - ゲーム終了フラグ

維持対象:
  - 選手データ
  - 球種設定
  - チーム名
```
