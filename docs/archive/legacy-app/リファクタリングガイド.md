# 野球シミュレーター リファクタリング ガイド

## はじめに：このガイドについて

このガイドは、あなたが作った野球シミュレーターを「もっと開発しやすい形」に整理するための手順書です。

**安心してください：**
- 難しい作業はClaude Code（AI）が行います
- あなたがやることは「指示を出す」「確認する」だけです
- わからないことがあれば、いつでもClaude Codeに質問できます

## なぜこの作業が必要なの？

### 今の状態（問題点）

今の野球シミュレーターは、**1つのファイルに全部の機能が詰め込まれています**。

```
baseball-simulator-v25_15.html （3,360行！）
```

これは例えると：
- 📚 **1冊の本に、小説も辞書も料理本も全部書いてある状態**
- 🏠 **1つの部屋に、寝室もキッチンもお風呂も全部ある状態**

こうなると：
- ❌ 「あの機能どこだっけ？」と探すのが大変
- ❌ 1箇所を直すと別の場所が壊れることがある
- ❌ 新しい機能を追加しにくい

### 整理後の状態（メリット）

ファイルを役割ごとに分けます：

```
src/
├── data/        ← データ（選手情報など）
├── logic/       ← 計算処理（物理演算など）
└── components/  ← 画面パーツ（スコアボードなど）
```

これは例えると：
- 📚 **小説は小説、辞書は辞書、料理本は料理本と別々の本にする**
- 🏠 **寝室、キッチン、お風呂を別々の部屋に分ける**

こうなると：
- ✅ 「スコアボードを直したい」→ `Scoreboard.jsx` を開けばいい
- ✅ 1箇所を直しても他に影響しにくい
- ✅ 新しい機能を追加しやすい

## Step 1: Node.jsのインストール

### Node.jsとは？

Node.jsは「開発に必要なソフト」です。
これがないと、ファイル分割ができません。

### インストール手順（Windows）

#### 1. ダウンロードページを開く

ブラウザ（Chrome、Edgeなど）で以下のURLを開きます：

```
https://nodejs.org/
```

#### 2. ダウンロードする

ページを開くと、緑色のボタンが2つあります。

```
┌─────────────────┐  ┌─────────────────┐
│  22.x.x LTS     │  │  23.x.x Current │
│   推奨版        │  │    最新版       │
└─────────────────┘  └─────────────────┘
        ↑
    こちらをクリック！
```

**必ず「LTS」と書いてある方（左側）をクリック**してください。
（LTS = Long Term Support = 長く使える安定版）

#### 3. インストーラーを実行する

ダウンロードしたファイル（例：`node-v22.x.x-x64.msi`）をダブルクリック。

#### 4. インストール画面の進め方

| 画面 | やること |
|------|---------|
| Welcome画面 | 「Next」をクリック |
| License Agreement | 「I accept...」にチェック → 「Next」 |
| Destination Folder | そのまま「Next」（変更不要） |
| Custom Setup | そのまま「Next」（変更不要） |
| Tools for Native Modules | **チェックを入れる** → 「Next」 |
| Ready to install | 「Install」をクリック |
| Completed | 「Finish」をクリック |

#### 5. パソコンを再起動する

インストールが終わったら、**パソコンを再起動**してください。
（これをしないと正しく動かないことがあります）

#### 6. インストールできたか確認する

再起動後、以下の手順で確認します。

**PowerShellの開き方：**

1. キーボードの `Windows` キー（旗のマーク）を押す
2. 「powershell」と入力
3. 「Windows PowerShell」をクリック

青い（または黒い）画面が開きます。これが「ターミナル」です。

**確認コマンドを入力：**

以下を1行ずつ入力して、Enterキーを押します：

```
node --version
```

成功すると、こんな表示が出ます：
```
v22.12.0  （数字は違っていてもOK）
```

次に：
```
npm --version
```

成功すると、こんな表示が出ます：
```
10.9.0  （数字は違っていてもOK）
```

**もしエラーが出たら：**
- パソコンを再起動したか確認
- もう一度インストールをやり直す
- Claude Codeに相談する

## Step 3: 開発サーバーの使い方

### 開発サーバーとは？

ファイルを編集すると、自動的にブラウザの表示が更新される便利な仕組みです。

### 起動方法

Claude Codeが起動してくれますが、自分で起動する場合：

1. PowerShellを開く
2. プロジェクトフォルダに移動：
   ```
   cd C:\Users\あなたの名前\プロジェクトの場所\baseball_simulation
   ```
3. 開発サーバーを起動：
   ```
   npm run dev
   ```

### 起動成功の画面

こんな表示が出たら成功です：

```
  VITE v5.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

### ブラウザで確認する

ブラウザ（Chrome、Edgeなど）を開いて、アドレスバーに以下を入力：

```
http://localhost:5173
```

または `localhost:5173` だけでもOK。

**「localhost」とは？**
- 「自分のパソコン」という意味の特別なアドレスです
- インターネットには公開されません
- 自分のパソコンでしか見れません

**「5173」とは？**
- 「ポート番号」と呼ばれる数字です
- Viteが使う番号がたまたま5173です
- 深く理解する必要はありません

### サーバーの止め方

PowerShellの画面で `Ctrl` キーを押しながら `C` キーを押す。

```
Ctrl + C
```

「止めますか？」と聞かれたら `Y` を押してEnter。

## 分割後のファイル構成（詳細説明）

```
baseball_simulation/
│
├── index.html         ← ブラウザが最初に読むファイル
├── package.json       ← 「どんな道具を使うか」のリスト
├── vite.config.js     ← Viteの設定
├── tailwind.config.js ← Tailwindの設定
│
└── src/               ← ソースコード（実際のプログラム）置き場
    │
    ├── main.jsx       ← プログラムの入り口
    ├── App.jsx        ← メインの画面（一番大事）
    ├── index.css      ← 見た目の設定
    │
    ├── data/          ← データを置くフォルダ
    │   ├── ballEffects.js     ← 球種の効果（ストレート、スライダーなど）
    │   ├── defaultPlayers.js  ← 選手のデータ
    │   └── constants.js       ← 数値の設定（反発係数など）
    │
    ├── logic/         ← 計算処理を置くフォルダ
    │   ├── physics.js     ← 物理の計算（打球の飛距離など）
    │   ├── gameRules.js   ← 野球のルール計算
    │   └── simulation.js  ← シミュレーションの中心処理
    │
    └── components/    ← 画面パーツを置くフォルダ
        ├── Scoreboard.jsx     ← スコアボード
        ├── Field.jsx          ← 野球場の絵
        ├── PitchLog.jsx       ← 投球の履歴
        ├── PlayerList.jsx     ← 選手一覧
        ├── PlayerEditor.jsx   ← 選手編集画面
        ├── Controls.jsx       ← ボタン類
        ├── StatsDisplay.jsx   ← 統計表示
        └── AccordionSection.jsx ← 折りたたみ部分
```

### フォルダの役割

| フォルダ | 役割 | 例え |
|---------|------|------|
| `data/` | データの定義 | 住所録、設定表 |
| `logic/` | 計算処理 | 電卓、計算式 |
| `components/` | 画面パーツ | ボタン、表、グラフ |

### ファイルの拡張子

| 拡張子 | 意味 |
|--------|------|
| `.html` | ウェブページの骨組み |
| `.css` | 見た目（色、大きさ、配置） |
| `.js` | プログラム（計算、データ） |
| `.jsx` | プログラム＋画面パーツ |
| `.json` | データのリスト（設定ファイル） |
| `.md` | ドキュメント（このファイル） |

## よくある質問（FAQ）

### Q: 元のHTMLファイルはどうなりますか？
**A: そのまま残ります。**
`baseball-simulator-v25_15.html` は削除されません。
万が一のときのバックアップとして置いておきます。

### Q: 見た目や機能は変わりますか？
**A: 変わりません。**
内部の整理整頓をするだけです。
使い方も見た目も今と同じです。

### Q: 途中でやめることはできますか？
**A: はい、できます。**
各ステップは独立しているので、いつでも中断できます。
元のHTMLファイルは残っているので、そちらを使えます。

### Q: エラーが出たらどうすればいいですか？
**A: Claude Codeに伝えてください。**
エラーメッセージをそのままコピーして送ると、
修正方法を教えてくれます。

### Q: コマンドを間違えたらどうなりますか？
**A: 大丈夫です。**
間違ったコマンドを入力しても、パソコンが壊れることはありません。
「そのコマンドは見つかりません」というエラーが出るだけです。

### Q: 「permission denied」と出ました
**A: 権限の問題です。**
PowerShellを「管理者として実行」してください：
1. 「powershell」で検索
2. 右クリック → 「管理者として実行」

### Q: 「localhost:5173」が開けません
**A: 以下を確認してください：**
1. 開発サーバーが起動しているか（`npm run dev` を実行したか）
2. PowerShellに「ready」と表示されているか
3. URLを正しく入力したか（http://localhost:5173）

### Q: ファイルを間違えて消してしまいました
**A: Claude Codeに伝えてください。**
元のHTMLファイルから復元できます。

## トラブルシューティング

### PowerShellが開けない

**方法1: スタートメニューから**
1. Windowsキーを押す
2. 「powershell」と入力
3. 表示された「Windows PowerShell」をクリック

**方法2: 右クリックメニューから**
1. エクスプローラーでプロジェクトフォルダを開く
2. 何もないところで `Shift` + 右クリック
3. 「PowerShellウィンドウをここで開く」を選択

### 「npm: コマンドが見つかりません」と出る

Node.jsが正しくインストールされていない可能性があります。

1. パソコンを再起動する
2. 再度 `node --version` を試す
3. それでもダメなら、Node.jsを再インストール

### 画面が真っ白

1. PowerShellでエラーが出ていないか確認
2. ブラウザの更新（F5キー）を試す
3. 開発サーバーを再起動（Ctrl+C → `npm run dev`）
