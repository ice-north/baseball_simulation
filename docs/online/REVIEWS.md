## スマホの事前采配と試合経過

スマホは打順画面から項目別の采配パネルを開き、基本方針・バント・代打と守備固め・先発の交代を編集できる。投手の役割は4人ずつ閲覧し、ローテーションと役割の変更はPCに残す。戻る・保存は下部に置き、既存の編成下書きと比較保存を共用する。保存失敗はパネル内にも表示し、閲覧のみの端末では再ログインが必要な理由を表示する。

試合成績には「試合経過」を追加した。同じ確定記録を回・打席と走塁／全投球・高さに応じたページ送りで閲覧する。スコア・カウント・走者・対戦中の選手・球種と球速を表示し、選択した長い結果名も確認できる。走塁の行に打者を走者として表示せず、継投の行は交代後の投手名を使う。PCの球場再生は維持する。

機能レビューでは、別の保存経路を増やしていないこと、PCで設定した投手役割や未変更の方針を保存時に落とさないこと、相手球団の閲覧に私的設定を追加しないこと、試合閲覧から更新APIを呼ばないことを確認した。320/360/390/767px・高さ640px（360pxではDPR3＝1080x1920）で、項目ごとのスクロール不要、投手詳細の重ね表示、画面移動・再読込・PC表示切替による下書き保持、保存失敗と再試行、相手球団の詳細、試合の最終得点までを配布HTMLで検査する。通信/Authはfixture、サーバーprojection・編成保存と試合記録は実コードを使用。`npm run check`、PC観戦・成績・認証・未保存編集のUI検査も実施。実クラウドでのログイン後の操作と実機iOS/Androidは未受入。
