# 対人版の成績ラベル

## 今回の範囲

通常ゲームの画面・試合計算・集計・保存形式は変更しない。対人版のサーバー投影と専用ビューだけで、既存の今季成績から基本ラベルを計算・表示する。ラベル一覧は保存せず、試合・AI・育成・契約評価には使用しない。

PCは「選手」の名前付近に最大3個。打撃／投球を切り替えられ、名前から今季成績を開く。スマホは「打順」から選手名を押すか「選手成績」へ進む。一覧は画面高に合わせた人数・3文字以内の略称ラベル最大3個、詳細は正式名のラベル最大3個と主要成績だけ。1080×1920の縦持ち相当（CSS360×640、倍率3）で10人とページ送りが収まる。日付・進行時刻の共通表示とブランドヘッダは一覧に重ねない。投手・控えも確認でき、成績一覧から戻っても編集中の打順を保持する。

## 判定

平均は対戦リーグの現所属4球団全員の今季成績から分子・分母を合計して算出する。自チーム、一覧ページ、背景リーグの選手で母集団を変えない。打撃は50打席以上、投球は15回以上を対象とする。比較対象や必要項目が不足する場合は付けない。

|ラベル|条件|
|---|---|
|アベレージヒッター|打率が平均+.035以上|
|パワーヒッター|本塁打率が平均1.5倍以上、ISOが1.3倍以上|
|長打型|ISOが平均1.3倍以上。パワーヒッターを優先|
|選球眼|四球率が平均1.4倍以上|
|出塁型|出塁率が平均+.040以上。選球眼を優先|
|三振／扇風機|三振率が平均1.35倍／1.7倍以上。扇風機を優先|
|盗塁B／盗塁F|10企図以上で成功率80%以上／60%未満|
|奪三振|K/9が平均1.3倍以上|
|四球|BB/9が平均1.4倍以上|
|一発|被本塁打/9回が平均1.5倍以上|
|制球安定|BB/9が平均0.7倍以下|

最大3個は基準からの突出度、同点時は固定順で選ぶ。正負の併存を認め、同系統の重複は出さない。平均0から倍率条件を成立させず、実測四球0と項目欠損を区別する。投手ポジションでも打撃記録を捨てない。盗塁死の欠損を0として成功率100%にしない。

既存集計には犠飛や敬遠の区別がないため、打席は「打数+四球+記録済み死球+犠打」、出塁率は「(安打+四球+記録済み死球)/(打数+四球+記録済み死球)」の概算で揃える。画面にも概算と表示する。ISOは長打数から算出し、投球回は保存されたアウト数を使用する。

## 検証・機能レビュー

- `check:online`内の`online-label-check.mjs`：閾値の境界、欠損と0、最低出場量、正負・排他・上限、4球団の加重平均、投打両方、状態非破壊と乱数不使用。
- `check:online:label-ui`：配布HTMLと実サーバー投影を使用。PC・スマホ320/360/390/767px（360pxは倍率3）、最大3ラベル、詳細、投打切替、Escape、フォーカス復帰、画面高に応じた行数とページ送り、打順の編集保持、閲覧で更新APIを呼ばないことを検査。通信・認証はfixture。
- 初回検証で見つかった詳細のフォーカス復帰、スマホ一覧の高さ、基準ちょうどの浮動小数点誤差を修正した。
- 既存の編集・認証fixture画面検査と、専用FileStoreを使う二人分の実API操作も回帰検証する。

ローカルで `check:full`、`build`、既存の実API画面・認証画面・編集画面、新しいラベル画面検査がPASS。最後の判定境界と編集保持の修正は専用検査でも再確認した。実サービス・実機の検証とは分けて扱う。

## 後続の範囲

添付計画全体の実装ではない。得点圏・対左・代打・初球・2ストライク後などの場面別記録とラベル、場面別成績表、通算ラベル、年度・リーグ別の確定比較値は未実装。存在しない過去の集計は推測で生成しない。

これらを追加する際、通常ゲームの共通試合処理に変更が必要なら先に相談する。Supabase/Vercel実接続と実スマホの受入は、従来どおり外部設定後に確認する。

## ラベルの見た目と略称

良い特徴を青、悪い特徴を赤の小さな能力札風に表示する。通常ゲームの表示や判定条件・選択順位は変えない。スマホ一覧は1人44pxのまま、代表1個から最大3個へ増やす。詳細は正式名、略称には正式名の読み上げとツールチップを付ける。

|正式名|一覧の略称|
|---|---|
|アベレージヒッター|アベヒ|
|パワーヒッター|パワヒ|
|長打型|長打|
|選球眼|選球眼|
|出塁型|出塁|

|盗塁B／盗塁F|盗塁B／盗塁F|

画面検査で、3個の札が数値と重ならず10人表示を維持すること、略称が3文字以内であること、詳細では正式名を読めることを確認する。スマホの詳細・メニューはブラウザ既定の最大幅による余りをなくし、画面幅いっぱいに揃える。
