# 対人版の選手情報と一覧比較

## 表示の原則

通常ゲームの画面・能力判定・シミュレーションは変更しない。対人ビューだけで、一覧は能力を色付きランク、詳細は換算前の実数値で表示する。打率やOPSなどの成績、年齢・疲労は数値のまま。

能力ランクは既存PC画面の `getAbilityRank` / `getRankColor` を共用する。90以上S、80以上A、70以上B、60以上C、50以上D、40以上E、それ未満F。球速は `(球速-115)*2.5`、投球スタミナは `/2` で判定する。元ゲームにGはない。欠損は「—」とし、最低ランクや平均値を補わない。

## 画面ごとの情報

| 画面 | 比較・判断する情報 | 詳細への導線 |
| --- | --- | --- |
| 今日 | 次の試合、先発枠の調子・疲労、各人の決定状態 | 先発選手名 |
| 選手 | 投打の基本成績、各記録、主要指標、調子・疲労、能力 | 各選手行 |
| 打順・編成 | 守備位置、打順、調子、投手の疲労とローテーション順 | 選手名または「情報」 |
| ドラフト・トライアウト | 年齢、位置、主要能力のランク | 候補選手名 |
| 戦力外 | 選手・年齢・位置を確認して選択 | 各選手の「情報」 |
| 試合 | 自球団／全体、結果／予定、勝敗・セーブ・ホールド投手 | 現在は試合概要まで |

先発枠はローテーション上の予定。実際の先発は進行時の疲労等で変わり得る。

## 成績一覧

打撃は基本、出場・安打、長打、四死球・犠打、走塁、打撃指標、打席率、守備、状態、打撃能力、守備能力。投球は基本、登板・勝敗、救援、被打撃・失点、先発・球数、投球指標、9回換算、状態、投球能力。

一度に4項目を比較する。項目名で昇順／降順を切り替え、ページを切る前に全選手を並べ替える。欠損は常に末尾、同値は元順。項目群を変えると並べ替えとページをリセットする。PCは能力一覧／成績一覧を切り替えられる。

OPS・出塁率・長打率・ISO、WHIP・K/BB・K/9・BB/9・被本塁打/9を確認できる。犠飛等の独立記録がないため、出塁率・OPS・打席関連率は概算表示。0で割る値は「—」、奪三振があり与四球0のK/BBは「∞」。投球回は内部のアウト数を `回.残アウト` に換算する。

## 選手詳細

画面遷移しないパネル内で「成績」と「能力・人物」を切り替える。能力は打撃・走塁、投球、球種、守備・捕手、9位置の適性、身体、精神・成長、打撃の特徴、プロフィールに分ける。身体の走力は `physical.speed` を参照する。調子は絶不調〜絶好調の5段階と矢印を併記する。

能力の実数値、球種レベル、フォーム、出どころ、コース適性、利き手、体格、出身等を既存データから閲覧する。コースと出どころの導出は元ゲームの決定的ヘルパーを利用し、閲覧で乱数消費や世界の更新をしない。球種が多いときは6件ずつページ送りする。

年度別・通算成績、試合の全打席／ボックススコア、経歴年表、将来能力予測は今回の表示範囲に含めない。WARなど元データから算出できない指標や、ゲームにない故障状態は作らない。

## 検証

`online-stats-view-check` は全既存記録の閲覧経路、指標の計算、欠損・0・∞、全選手ソート、能力ランクと詳細数値を確認する。`online-label-ui-check` は実projectionと配布HTMLを使い、320/360/390/767pxで投打の全項目、列幅、ソート、能力詳細、フォーカス復元、編成の未保存変更維持を確認する。通信はfixture。360×640 CSS px・3倍描画を1080×1920の縦持ち相当として使用し、実機とは区別する。
