# 対人版の未保存入力

編成と提出案の入力・編集開始時のサーバー状態・未保存フラグを、ログインセッション／球団／年度／手続き単位で保持する。ホームや選手画面への移動、PC/スマホ表示の切替、同じタブの再読み込みで復元する。タブ内のsessionStorageを使い、利用禁止の場合もメモリ内の画面間保持は続ける。未保存なら再読み込み・タブを閉じる際にブラウザ標準の確認を要求する。

保存や明示的な編集取消で未保存フラグを解除する。別セッション、別球団、次年度、別手続きには案を流用しない。古い編集開始時点も保持し、復元した古い案によるサーバー内容の上書きは既存の比較検査で拒否する。勝手な自動送信は行わない。スマホにも編集中・未保存の案であることを表示する。

機能レビュー：状態の保存先だけを追加し、更新API・ゲーム計算・通常ゲームの保存は変更していない。配布HTML検査で、編成とキャンプ案の画面移動／表示切替／再読込、取消、別手続きへの持越し防止、自動送信なしを確認。既存の認証更新・編集競合検査も再実行する。端末間の未保存入力共有は対象外で、共有するにはPCで「下書きを保存」する。
