## 気づいたが直していないもの

- オンラインの `finalRankings`（年度の最終順位の写し）は一人用・オンラインのどちらからも読まれていない。オンラインでは保存の形なので、消すなら ONLINE_SCHEMA を上げて移行の段を足す必要があり、今回は残した。
- App.jsx に以前からの使われない import がいくつかある。モジュールの読み込み順に効いている可能性があり、確かめずに消すと危ないので残した。
- 指導者を解任して同じ人をまた呼ぶと、解任の回数（fired）と和らぎ（mellowed）の両方が付く（G1-7）。害は小さいが、どちらか一方にするのがよい。
- 試合に必要な人数の判定が2通りある（TryoutScreen の `getUserShortage` と `lineup.js` の `rosterShortage`。前回からの残り）。
- 順位表で名前の無い参加者に「（プレイヤー）」と添える。名前が無いときは何も添えないほうが自然だが、表示名の決まりにかかわるので残した。
- オンラインの選手の詳細で、野手にも投球の枠が出る（二刀流の起用のため意図した動き）。
- Web の初期メンバー選び（PackSelect）とアプリで、セットのカードの見せ方が違う。
- アプリの選手シートに打撃コースの図が無い（Web にはある）。
- `online-edit-ui-check` は混み合うと「更新」の待ちで落ちることがある（2ab24f3 で一部直した）。`pool-leak-check` の時々の落ちは 3585aa8 で直した。
- 大学の春の入れ替え戦で自分の部が変わっても、その年の設定の球団（settings.teamNames・leagueConfig）は年度更新まで春の部のまま（順位表と秋の日程は新しい部）。年の途中で変えると表彰の対象の球団が変わるので、今回は年度更新でそろえるところまでにした（ee7b35e）。
- 一人用のトライアウトで、「指名終了」を押せない理由（試合に出る最低限。例「捕手があと1人必要」）と「編成不足」の枠（理想の人数）とで、数が違って見えることがある。
- 一人用の1280幅のキャンプの表は、練習を組む列を右に留めた代わりに、読むだけの列（前年成績など）は留めた列の下を横に流れる（1400幅でも一部は横に送る）。オーダー画面は 1152px より狭いと、守備配置を見るのに下へ送る。
- 検査で確かめていないもの: チーム情報の「推薦（自動）」（画面の検査が大学の2年目まで進まない）。「注目度: NaN」の検査は2年目にランクが変わった回でしか効かない。アプリで端末を回す検査（7f8ef3b）は、このコンテナでは回せないので CI で通ることだけを確かめた（直す前に落ちることは確かめていない）。
