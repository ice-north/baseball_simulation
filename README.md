# 野球シミュレーター v2

リアルタイム物理演算による野球シミュレーションゲーム

## 🚀 起動方法

### かんたん起動（Windows）

`ゲーム起動.cmd` をダブルクリックするだけです。
Node.js の有無を確認し、初回だけ `npm install` を走らせてから開発サーバーを
起動し、ブラウザを自動で開きます。終了は Ctrl+C かウィンドウを閉じるだけ。

### 手動で起動する場合

初回セットアップ
```bash
npm install
```

開発サーバー起動
```bash
npm run dev
```

ブラウザで http://localhost:3000 が自動的に開きます。

> **必ず `http://localhost:3000` で開いてください。**
> セーブデータはブラウザの中に、**このアドレス専用**の領域として保存されます。
> ポート番号が違うと（`:3001` など）ブラウザは別のサイトとして扱うので、
> 前のセーブが1件も見えなくなります。
> 3000番が使用中のときは、わざと起動に失敗するようにしてあります
> （`vite.config.js` の `strictPort`）。閉じ忘れた起動ウィンドウを閉じてから
> 開き直してください。

### プロダクションビルド
```bash
npm run build
npm run preview
```

## 💾 セーブデータについて

セーブデータは **ブラウザの中**（`http://localhost:3000` 専用の領域）に保存されます。
ゲームのフォルダには入らないので、フォルダをコピーしても引き継げません。

- **控えを取る / 別のPC・別のブラウザへ移す**
  ゲーム内の「セーブ＆ロード」→ 各スロットの **⬇ ファイルに書き出す**。
  移す先では **⬆ ファイルから読み込む** で戻せます。
- **ブラウザのデータを消去すると消えます。** 大事な進行はファイルに控えてください。

### 「セーブが消えた」ときは

ほとんどの場合、**消えていません**。アドレスが変わって見えなくなっているだけです。

1. アドレスバーが `http://localhost:3000` になっているか確認する
2. 違うポート（`:3001` など）だったら、起動ウィンドウを全部閉じて開き直す
3. 前のセーブが別のポートにある場合は、いったんそのポートで開いて取り出す

```bash
# 例: 3001 に取り残されたセーブを取り出す
npm run dev -- --port 3001
```
そのまま「セーブ＆ロード」→「⬇ ファイルに書き出す」でファイルに出し、
3000 で開き直して「⬆ ファイルから読み込む」で戻します。

4. 遊んでいたときと**同じブラウザ**で開いているかも確認してください
   （Chrome のセーブは Edge からは見えません）
